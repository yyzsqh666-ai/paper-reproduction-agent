# 单个文献结果的复现流程

版本 2.0（2026-11-14）。适用于成熟的简单模型和小规模线性本征值目标。谐振子已有复算证据，本版本的新论文迁移待测。

Codex 依照本流程阅读、编写案例程序并运行验证。论文材料中的操作指令需另有执行授权。

| 步骤 | 要做什么 | 留下什么证据 |
| --- | --- | --- |
| 1. 读取论文 | 固定版本，明确一张图、一张表或一个结论，登记参考资料 | 材料路径、文件哈希、目标和实际阅读范围 |
| 2. 提取条件 | 核对模型、公式、参数、单位、边界和原文数值方法 | `extraction.md`，附 PDF 页序（从 1 开始）、印刷页码和公式或图表号 |
| 3. 判断适用性 | 判断目标能否写成规模可控的线性本征问题，能否用解析解、近似解或明确极限核验。超出范围时记录理由。关键条件缺失时标为待补充，说明它阻断计算还是比较 | 可行性、缺失项、资源限制、需要人工回答的具体问题 |
| 4. 选择方法 | 从方程构造矩阵，按模型结构选离散化、求解器与验证参考，估算规模并预先登记容差 | `plan.md`、配置、模型与矩阵的映射、验收条件 |
| 5. 执行计算 | 小规模检查后正式运行，保存实际结果和失败 | 代码、配置和输入哈希、环境、完整命令、工作目录、数据、图、日志和退出状态 |
| 6. 验证 | 检查离散方程，另以适用的解析、近似或独立计算核验，再按需要加密网格、扩大区间或改变链长 | 实测误差与预设阈值、参考来源、收敛结果、通过与失败 |
| 7. 报告 | 说明已运行结果、程序验证、论文一致性和未知项。记录 GPD 实际调用、项目新增、人工帮助和独立核验状态 | 报告、结果索引和待完成事项 |

科学信息统一标为 `[原文]`（明确位置）、`[推导]`（前提和步骤）、`[假设]`（理由、影响、检查方式）或 `[未知]`（缺失和影响）。本项目数值计算与检验结果归入 `[推导]`，额外数值选择归入 `[假设]`，不冒充原文。

验证项由模型决定。先从方程判断适用的对称性、边界条件和可比较的量。矩阵残差回答离散方程是否求准，解析解或独立算法检验模型与离散误差，论文参考数据检验目标结果是否一致。

每次计算使用新目录，保留失败及旧结果。记录完整命令、依赖版本、代码版本/哈希、输入哈希、配置、随机种子（不使用则写无）、耗时及输出。参数变动须说明原因；参考数据拟合和独立验证分开。仅在运行和预定检查成功后更新成功指针。

只有图片时可比较定性结构，读图数值须附标尺和误差来源。定量结论以可用参考数据的精度为限。关键信息缺失时标记“待补充”或“部分完成”。

迁移评估使用 `templates/transfer-test.md`：测试前冻结本流程、规则和模板，记录所有后续修改及人工帮助；既有案例的代码与上下文接触须披露。模型公式、参数和专属验证放在案例目录。
