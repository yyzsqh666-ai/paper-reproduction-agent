# Roy（2013）表 II 的 H₂ 复现计划

本文件在计算前保存。可行性为按论文式 (1)–(4) 独立求解与定量比较可执行。逐字复跑作者实现待补充（U1–U3）。目标限于 PDF 第 7 页／印刷第 7 页表 II 的 H₂、ℓ=0、n=0,1,2 的 `−E (PR)`。

## 主计算与物理核验

[推导] 令 ξ 为配点坐标、J=dr/dξ=L(2+α_g)/(1−ξ+α_g)²。原子单位下对 χ=√J ψ 变换式 (2) 的动能，得 −(1/2μ)J⁻¹∂²_ξ J⁻¹，并加上与 3(J′)²−2J″J 成正比的映射势。对这里的代数映射，该组合为零。按式 (7) 的 Aᵢ=χᵢ/P_N(ξᵢ)，由式 (4) 对 gⱼ 求二阶导数。记 h=(1−ξ²)P′_N，由 Legendre 方程 h′=−N(N+1)P_N。对内部 ξᵢ，h(ξᵢ)=h″(ξᵢ)=0，故非对角项 gⱼ″(ξᵢ)=−2P_N(ξᵢ)/[P_N(ξⱼ)(ξᵢ−ξⱼ)²]。对角项由 h 展开得 gᵢ″=h‴/(3h′)=−N(N+1)/[3(1−ξᵢ²)]。相似变换吸收 P_N 比值，故对称二阶矩阵 S 的非对角项为 −2/(ξᵢ−ξⱼ)²、对角项如上。只保留内部方程，Hᵢⱼ=−Sᵢⱼ/(2μJᵢJⱼ)+δᵢⱼV(rᵢ)。以 Jacobi P_(N−1)^(1,1) 的零点求内部配点，因 dP_N/dξ=(N+1)P_(N−1)^(1,1)/2。

[推导] 独立核验使用全轴 Morse 解析谱。令 λ=√(2μDₑ)/a、y=2λ exp(−a(r−rₑ))、s=√(−2μE)/a。取 ψ=yˢe^(−y/2)f(y) 后，f 满足 y f″+(2s+1−y)f′+(λ−s−1/2)f=0。两侧平方可积要求多项式终止，得到 n=λ−s−1/2、s>0 和 Eₙ=−a²(λ−n−1/2)²/(2μ)。本核验的全轴将径向原点延伸到 r→−∞。记录解析波函数在 r=0 和 r_max 相对解析态峰值的幅度，以诊断边界差异，并按预定阈值比较其与收敛径向计算。端点幅度不充当严格的能量误差上界。

## 执行次序和资源

1. [假设] 小规模 GPS 检查 N=80、r_max=30 a₀，检查多项式导数、负能、排序、节点数和离散残差。模型参数沿用表 I。
2. [假设] 论文一般设置 N=300、r_max=200 a₀，作为作者设置复算的独立一栏。随后固定 r_max=200 a₀ 执行 N=450、600、750，使用 N=750 为主报告的收敛值。固定 N=750 检查 r_max=160、240 a₀。每组 α_g=25。该预定扫描检验网格和盒长误差，严禁按表 II 选择主结果或拟合输入。
3. 求三条解析谱及边界幅度，以独立核验表报告。最后载入 PR 数据并比较两套 GPS 结果，输出含有符号偏差、绝对偏差与相对偏差的逐态 CSV。
4. 工作目录为案例根目录。命令为 `..\..\.venv\Scripts\python.exe run.py --config config.json`（PowerShell 执行见重跑说明）。仅用本机 CPU，一条 BLAS 线程，NumPy、SciPy、threadpoolctl，确定性求解，无随机种子。每次执行分配新的 evidence 子目录，写入配置、哈希、环境、命令、计算表、日志及状态，失败保留记录。

[假设] 共 7 组矩阵，最大 749×749，单个 float64 矩阵约 4.49 MB。采用稠密对称求解，内存 O(N²)，时间上界量级 O(N³)。多份矩阵及运行时预计低于 0.5 GB，预计总计算在 60 秒内。预算上限为 20 分钟、2 GB（十进制），记录 Windows 的进程峰值工作集和峰值提交计费量（可用时）及实际耗时，从 N=80 启动检查记录实际时间。
