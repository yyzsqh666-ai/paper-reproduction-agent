# 图 1 复现计划（计算前登记）

1. 已阅读 arXiv:0906.5138v1 第 1 页式 (1)、第 2 页图 1、图注及其下正文，核对第 5–6 页的图 3 说明。图 1 的目标是标准实 Airy 振幅。原图为 312 × 192 像素的位图。
2. 取图中标出的无量纲自变量 −10 ≤ s ≤ 10。线性势的衰减解适用，实验计数、模式占据、镜面截断和波函数归一化均不参与。图中的物理变量换算另作量纲核对。
3. 在含两端点的等距网格上取 2001 点。用标准 Airy 复积分沿竖直线平移后的实积分作梯形求积，固定实部 1，虚部从 0 到 10，步长 0.01。CSV 保存双精度值。仅用计算值作图。
4. 独立按 Airy 微分方程在原点展开，以标准归一化初值和高精度十进制系数在每隔 0.5 的位置复算。全体 41 点最大绝对差 ≤ 1e−10。积分步长减半并扩区间至 12 后，全网格最大绝对差 ≤ 1e−10。CSV 应有 2001 个有限值，含原点、两端点，有六个变号区间，正半轴为正且递减。
5. 与原图定量比较时使用图中刻度固定标定，不拟合振幅、相位或坐标。以放大图目读的四峰三谷为独立地标，逐点横向误差 ≤ 2 个原生像素、纵向误差 ≤ 2 个原生像素。另按计算曲线在原图上找最近墨迹，跳过距两轴 2 像素内的点，95% 距离 ≤ 2 原生像素。后者为单向几何距离，须结合地标一起判断。正侧尾部与轴重合处仅作数值验证。
6. 保存图、CSV、脚本、调用命令、版本、原文哈希和实测误差，报告区分原文、推导、假设和未知。若检验失败，保留实测值并说明。
