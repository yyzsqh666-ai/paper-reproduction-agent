## [推导] 实空间矩阵

前提：式(1)(2)及上表基底。步骤：对每个 ket-bra 项，把 ket 写为行、bra 写为列，再按原文求和范围连接；得到下式。

使用从 0 开始的代码下标 a=2n、b=2n+1（n=0,…,N-1）：

H[b,a]=v1，H[a,b]=v2，H[a,a]=iu，H[b,b]=-iu；n<N-1 时 H[a+2,b]=w1，H[b,a+2]=w2。不自动添加复共轭，不添加 H[A1,BN]。

三胞矩阵（u=0）：

```text
 0  v2  0   0   0   0
v1   0 w2   0   0   0
 0  w1  0  v2   0   0
 0   0 v1   0  w2   0
 0   0  0  w1   0  v2
 0   0  0   0  v1   0
```

## [推导] 用于验证的推导，不替代有限链求解

前提均为图4的 u=0、相同正反向跃迁及开放链。步骤分别为：用正负交替矩阵作用于跨分格跃迁；令 sin(t) 或 cos(t) 为零后分解成2阶块；在零能方程中消去另一分格振幅。

- Γ=diag(1,-1,…)，ΓHΓ=-H，因此 E 与 -E 配对（p.2 手征对称性说明推广到有限链）。
- t=0：N-1 个胞间二聚体，每个 E=±1，另有孤立 A1、BN 的两个零模。
- t=π/2：N 个独立胞内二聚体，每个 E=±exp(iπ/5)，故 Re E=±0.80901699、Im E=±0.58778525。
- 半无限链 E=0 的左端递推 A_(n+1)=-(v/w)A_n，因此空间权重比为 |tan t|²；仅 t<π/4 可归一化。有限链两端耦合导致劈裂，不强制精确置零。
- p.6 附录B 式(B1)描述周期体谱并说明 t=π/4 的体隙闭合；仅作为临界位置依据，不用于生成目标 OBC 能谱。
