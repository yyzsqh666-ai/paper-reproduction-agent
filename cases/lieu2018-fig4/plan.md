# 图4执行与验证方案

预先制定于目标扫描之前；实际执行状态与数值见 records、verification.md。严格依据 extraction.md；不计算 Berry 相位或其他图。

1. 用相互不同的复数 v1/v2/w1/w2 构建三胞矩阵，与手写矩阵逐元素检查，从而暴露方向颠倒、误取共轭和周期闭合错误。检查通过才运行大链。
2. NumPy complex128 矩阵，SciPy `linalg.eig` 求全部复本征值及右本征矢。基底与矩阵元见 extraction.md。主扫描 N=100、401点（含端点）；加密801点与主网格嵌套，不连接不同参数的能级，不按实部排序追踪。
3. 保存每个参数所有复本征值、右本征矢、空间权重、端点权重、IPR、残差和标签。归一化 sum_j|ψ_j|²=1；|ψ|²只称空间权重，不解释为一般非厄米体系的守恒概率。
4. 端点区域为左右各5个原胞（各10格点）。W_end>0.5 标为端点局域；IPR=sum_j|ψ_j|⁴作为辅助指标。扫描阈值0.3/0.5/0.7，并对临界点附近报告分歧。t=0的大简并二聚体可能被 eig 返回为局域体态，需进行简并子空间检查：在每个数值简并簇中，对右本征矢张成空间正交化，检查端点投影谱；仅当整个簇的最小端点权重大于阈值，才给整个簇端点局域标签。混合子空间标为不确定，不任意染红。非零二聚体简并簇含内部二聚体，最小权重为0。
5. 近零边界双态的左右组合用子空间总权重/端点投影本征值说明；正交化后的基只是分析子空间，不称它为各自原始本征态。展示 t/π=0、0.15、0.24、0.25、0.30、0.5 的代表态空间分布。
6. 验证小链、残差、手征关系、±E配对、两个二聚化极限；N=20/50/100 在 t/π=0.20、0.23、0.24、0.25、0.26 比较最低模劈裂与局域性；相位从π/5降至0，零相位谱对照独立二分块奇异值构造 ±s(Q)，不用 Hermitian eig 求目标谱。

## 预设误差标准

- 连接矩阵逐元素完全一致；Γ关系相对 Frobenius 误差≤1e-14。
- 每态残差 ||Hψ-Eψ||₂ / ((||H||_F+|E|)||ψ||₂) ≤1e-12。该残差检验后向精度，不保证近例外点的本征值前向精度。
- ±E配对采用复平面一一最小费用匹配，最大差/ max(1,max|E|) ≤1e-9；极限和厄米回归绝对误差≤1e-10（能量量级1）。容差比双精度舍入大，足以容纳200阶矩阵求解。
- 加密网格共有点的谱集合一一匹配误差≤1e-10；额外统计相邻参数谱集合变化与阈值过渡区，网格不是逐能级追踪。采样定位精度至多一个粗步长π/800，不能据此宣称精确临界点。
- 阈值敏感性不作为求解器通过/失败项；预期近临界处定位随阈值变动，必须公开。
- 图片只有有限分辨率；定性比较结构。若读端点，先以轴刻度确定像素映射，按±0.03能量单位保守估计读数误差，不能把读数精度当求解精度。原图与图注若冲突则单独报告，不能以“通过”掩盖。
