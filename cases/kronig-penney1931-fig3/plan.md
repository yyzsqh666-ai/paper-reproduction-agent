# 运行前计划与验收 · Kronig–Penney（1931）§1 图 3

## 可行性

[推导] 图 3 的无量纲能带计算具备所需模型、边界条件及全部坐标定义，可行。它是一维单胞自伴线性本征问题，带缘可以由分段解析式直接确定，并可用小矩阵独立核验。材料位置和推导见 [提取](extraction.md)。[未知] U1 阻断与扫描图的定量误差判断，U2 只影响换算绝对能量，U3 只影响原作者绘图算法的追溯。三项均不阻断目标区间计算。U1 和 U2 若需补充，具体材料分别是原图数值点表与晶格尺度 \(a\)。

## 算法及步骤

1. [假设] 采用两段各 600 等分，拼接位置只保留一组。定义绘图位置 \(u=P/(4\pi)\)（左）或 \(u=2-4\pi/P\)（右）。数据同时保存原图两段刻度、\(u\)、\(P\)、带号和上下边。\(P=0,\infty\) 分支显式取极限；\(\infty\) 在 CSV 记为 inf。每带分别用直线连接密集数据点填充阴影。
2. [推导] 二分只求下缘。左段求 \(z\sin(t/2)-P\cos(t/2)=0\)，\(t=z-(n-1)\pi\)；右段写 \(d=n\pi-z\)，求 \(\sin(d/2)-[4\pi/P]\,z\cos(d/2)/(4\pi)=0\)。两式与提取记录的单调根等价，避免切函数极点与右端无穷参数。上缘直接用 \(n\pi\)。[假设] 用固定 52 次二分。
3. [推导] 独立核验使用均匀网格 \(j/N\)，哈密顿量将 \(-\partial_\xi^2\) 离散为对角 \(2N^2\)、邻点 \(-N^2\)，跨胞角元 \(-sN^2\)（\(s=\pm1\)），并在节点 0 加 \(2PN\) 以保存势垒积分。分别用 NumPy 对两个实对称矩阵求本征值，各取最低三个，再合并排序得到前三带的六个边缘，最后除以 \(\pi^2\) 得图 3 单位。该步骤从实空间哈密顿量出发，独立于式 (6) 求根。[假设] 对 \(P/(4\pi)=0,1/4,1,4\) 用 \(N=64,128,256\)；小试用 \(P/(4\pi)=0,1\) 与 \(N=32,64\)。
4. [假设] 小试采用两段各 4 等分检查端点、序号、残差与两层网格。小试成功后重开目录，正式运行并输出图。最后复查图和 CSV 对应关系、参考图结构与交付文件。

## 执行环境和资源

[假设] Windows PowerShell 调用本机 Anaconda Python（NumPy、Matplotlib Agg，无网络和 GPU，固定单线程 BLAS，无随机数）。从本案例目录执行 `pwsh -NoProfile -File ./run.ps1 -Mode smoke`，通过后执行 `pwsh -NoProfile -File ./run.ps1 -Mode full`。参数见 `config.json`。每次在 `evidence/<时间戳和阶段>/` 生成新目录，保留命令和实际退出状态。通过全部计算验收后再更新 `latest-success.json`。

[假设] 正式 1,201 个横坐标、3,603 行带边。计算量约 \(1.9\times10^5\) 次二分函数评估，加 24 次实对称本征值求解（每次矩阵阶数至多 256）。单个最大矩阵 0.5 MiB，预估进程峰值工作集低于 500 MiB，总运行低于 1 分钟，满足 20 分钟及 2 GB 预算。小试直接测耗时和内存，正式运行记录两者。
