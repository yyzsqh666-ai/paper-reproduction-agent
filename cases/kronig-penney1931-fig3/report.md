## 原图坐标、势垒与能量

[原文] 图 3 左半以 \(P/(4\pi)\) 为横坐标，由 0 到 1。右半以 \(4\pi/P\) 为横坐标，由 1 到 0。接缝为 \(P=4\pi\)，两侧等宽，全图从左到右均对应 \(P\) 增加。阴影是允许的 \((\beta a/\pi)^2\)，纵轴刻度为 0、1、4、9。（PDF 第 5 页／印刷第 503 页，§1 末段与图 3。）

[原文] \(W\) 是以自由区势能为零点的能量，\(\beta=\kappa\sqrt W\)，\(\kappa^2=8\pi^2m/h^2\)。矩形势垒在 \(b\to0,\ V_0\to\infty\) 时取 \(P=\lim \gamma^2ab/2\)，其中 \(\gamma=\kappa\sqrt{V_0-W}\)。（PDF 2／500，图 1、式 (1)；PDF 3／501，式 (5) 及页末。）[推导] 固定有限 \(W\) 后，\(P=mag/\hbar^2\)，\(g=\lim V_0 b\) 为每个势垒的积分强度。代入 \(\beta\) 得

\[
y=(\beta a/\pi)^2=\frac{W}{E_{\rm box}},\qquad E_{\rm box}=\frac{h^2}{8ma^2}=\frac{\pi^2\hbar^2}{2ma^2}.
\]

\(E_{\rm box}\) 是宽度 \(a\) 的无限深势阱基态能量，\(P\) 与 \(y\) 均无量纲。[未知] 图 3 未为 \(a\) 指定物理长度，换算 eV 待补充。

## 带边如何得到

[原文] PDF 3／501 的匹配条件要求有限势垒两段的波函数及一阶导数匹配，单胞边界满足 Bloch 条件。取零宽势垒极限后，令 \(z=\beta a\)，式 (6) 给出 \(F(z)=\cos z+P\sin z/z=\cos(\alpha a)\)。在无限晶格中 \(\alpha\) 可连续变化，所以允许带满足 \(|F|\le1\)。（PDF 4／502，式 (6)、图 2 及邻文。）

[推导] 令 \(z=(n-1)\pi+t\)，\(0<t<\pi\)。在这一段，\((-1)^{n-1}F\) 大于 \(-1\)，与 \(+1\) 的差为 \((\sin t/z)[P-z\tan(t/2)]\)。由 \(z\tan(t/2)\) 严格增加，得到唯一的下缘方程 \(P=z\tan(t/2)\)。上缘恒为 \(z=n\pi\)，即 \(y=n^2\)。[假设] 每半横轴采用 600 个等宽小区间，接缝计算一组，有限 \(P\) 的下缘用 52 次括区间二分，两个端点用解析极限。

| 势垒强度 | 第一带 \(W/E_{\rm box}\) | 第二带 \(W/E_{\rm box}\) | 第三带 \(W/E_{\rm box}\) |
| --- | ---: | ---: | ---: |
| \(0\) | \([0,1]\) | \([1,4]\) | \([4,9]\) |
| \(4\pi\) | \([0.747352317,1]\) | \([3.023882621,4]\) | \([6.915589294,9]\) |
| \(8\pi\) | \([0.858571445,1]\) | \([3.440842764,4]\) | \([7.765226028,9]\) |
| \(\infty\) | \([1,1]\) | \([4,4]\) | \([9,9]\) |

[推导] 表中前三行是闭区间，最后一行给出收缩后的极限。CSV 的 `branch` 为 left、join 或 right，`P_over_4pi` 与 `four_pi_over_P` 在各自适用半轴填值，接缝两列都为 1，每个接缝带号各一行。`x_plot` 是图上从 0 到 2 的连续位置，左段等于 \(P/(4\pi)\)，右段等于 \(2-4\pi/P\)。`y_lower` 与 `y_upper` 为绘图纵坐标，`beta_a_lower` 与 `beta_a_upper` 为对应的 \(z\)。右端 `P=inf` 是解析极限。

## 可量化核验

| 验收项 | 实测与结论 |
| --- | --- |
| A1 坐标与完整性 | [推导] **达标**。1,201 个横坐标，接缝一组，3,603 行。最大坐标映射误差 \(2.22\times10^{-16}\)，阈值 \(10^{-14}\)。图从同一 CSV 读入。 |
| A2 带边与区间 | [推导] **达标**。最大色散残差 \(1.03\times10^{-12}\)，阈值 \(10^{-9}\)。上带边恰为 1、4、9。有限 \(P\) 的带中点最大 \(|F|=0.253\)，禁止区中点最小 \(|F|-1=5.55\times10^{-6}\)。每条下带边都随 \(P\) 上升，各有限 \(P\) 带宽为正，采样的正 \(P\) 处带间隙为正。 |
| A3 物理极限 | [推导] **达标**。自由极限的三个区间首尾相接，强势垒极限为 1、4、9。另算有限 \(P=4\pi\times10^6\)，最大带宽 \(2.86\times10^{-6}E_{\rm box}\)，阈值 \(10^{-5}E_{\rm box}\)。参照 PDF 4／502 末段与 PDF 5／503 页首。 |
| A4 独立有限差分 | [推导] **达标**。按周期与反周期两种边界分别对实空间离散哈密顿量求本征值，在 \(P/(4\pi)=0,1/4,1,4\) 处逐边比较。\(N=64,128,256\) 的最大误差分别为 \(1.62529\times10^{-2},4.06542\times10^{-3},1.01649\times10^{-3}\)，以 \(E_{\rm box}\) 为单位。最细网格阈值 \(2\times10^{-3}\)。两次加密的误差比分别为 0.250136 和 0.250034，低于 0.35，符合二阶收敛预期。 |

[推导] 独立差分从 \(-\partial_\xi^2+2P\delta(\xi)\) 出发，\(\xi=x/a\)。它在节点 0 加入对角势 \(2PN\)，并令跨胞耦合带 \(+1\) 或 \(-1\) 的 Bloch 相位。该本征值计算不调用带边求根公式，比较值只在最后的误差计算中使用。A2 的残差检验回答所求根是否满足原式，A4 衡量两种算法在选定点的带边差异。
